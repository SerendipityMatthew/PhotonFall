**线性 vs 分叉**：目前章节组织是**松散线性**的——从光进入到照片出来。但知识并不严格单向流动：
- HDR（第 6 章 28）其实依赖像素（LOFIC，第 3 章 17）+ 多帧算法（第 6 章 33 计算摄影）
- 色彩空间（第 6 章 29）依赖 ISP CCM（第 5 章 26）+ 微透镜 CFA（第 2 章 12）
- 图像格式（第 6 章 30）依赖色彩空间 + 噪声（量化误差）

当前用 `related: [idx, ...]` 字段表达这些横向连接（已覆盖全部 34 步），抽屉里渲染为跳转芯片。

## 现有覆盖的广度评估

逐领域扫一遍 spec 列的「需要补充的知识领域」，对照项目现状：

### A. Optical Engineering

| 子话题 | 当前覆盖 | 状态 |
|---|---|---|
| Radiometry / Photometry | 一笔带过（第 10 步快门：进光量、EV） | 缺口 |
| Irradiance / Radiance / Etendue | 未覆盖 | 缺口 |
| Entrance pupil / Exit pupil | 隐含（第 5 步入瞳 75 mm） | 轻度 |
| Chief Ray Angle | 第 13 步（微透镜偏移）显式讲到 | ✓ |
| Telecentric optics | 未覆盖 | 缺口 |
| PSF / OTF | 第 5 步 hard 栏讲到 | ✓ |
| Sagittal / Tangential MTF | 未覆盖 | 缺口 |
| Field curvature | 第 7 步（镜片组）提及「场曲」 | ✓ 轻度 |
| Wavelength-dependent MTF | 未覆盖（色差分开讲） | 缺口 |

**评价**：已覆盖核心的 PSF / OTF / MTF / CRA / 场曲 / 像差。缺的是 Radiometry / Etendue / 光锥；可以在第 1 章开头加一个**辐射度 / 光度**基础的小步，或在第 5 步光圈节扩展。Telecentric optics 太窄，不必加。

### B. CMOS Semiconductor Manufacturing

| 子话题 | 当前覆盖 | 状态 |
|---|---|---|
| Epitaxy | 未覆盖 | 缺口 |
| Ion implantation | 未覆盖 | 缺口 |
| STI / DTI | 第 18 步（像素结构）hard 栏提及 DTI（深沟槽） | ✓ 轻度 |
| Backside thinning | 第 18 步 hard 栏「要把硅背面减薄到几 µm」 | ✓ |
| Wafer bonding / Hybrid bonding | 第 18、20 步（堆栈）讲到 | ✓ |
| Wafer-to-Wafer / Die-to-Wafer | 未明确区分 | 缺口 |
| TSV | 第 18 步 hard 栏提及「TSV / 铜柱」 | ✓ 轻度 |
| Metal interconnect | 第 18 步讲到「金属布线挡光」 | ✓ |
| Pixel isolation | 第 18 步 hard 栏讲到 DTI | ✓ |
| Manufacturing yield | 第 20 步（堆栈 LOFIC）「键合点对准和良率都难」 | ✓ 轻度 |

**评价**：核心的 BSI 工艺、堆栈键合、DTI 都有。真正缺的是**前端工艺**（epitaxy / 注入），但这些属于通用半导体知识，不见得是 PhotonFall 核心。建议**不单开章节**；可以在第 4 章末加一段 150 字的「半导体工艺小结」，列 epitaxy / implantation / 后端 metal → BSI 减薄 → bonding 的时序。

### C. Human Vision & Color Science

| 子话题 | 当前覆盖 | 状态 |
|---|---|---|
| L / M / S cones | 未覆盖 | **大缺口** |
| Rod cells | 未覆盖 | 缺口 |
| Photopic / Scotopic / Mesopic | 未覆盖 | 缺口 |
| Chromatic adaptation | 第 26、29 步隐含（CCM 要按光源选） | 轻度 |
| Color constancy | 第 26 步隐含 | 轻度 |
| Metamerism | 未覆盖 | 缺口 |
| Visual sensitivity | 未覆盖 | 缺口 |
| HDR perception | 第 29 步（PQ Barten 曲线）讲到 | ✓ 轻度 |
| CIECAM02 / CIECAM16 | 第 29 步 iq 节讲到 | ✓ |

**评价**：这是**最大的缺口**。整个项目讲从光子到照片，但没讲「人眼怎么接」。建议在**第 6 章（周边）之前**插一个新章或新步：「人眼：看到的是什么」。覆盖 LMS 锥 / 杆视 / 光度视 / 暗视 / 色恒常。它是色彩空间、CCM、HDR 感知的理论前置。

## 整体缺口优先级

按「会不会导致用户误解 / 知识不闭环」排序：

| 缺口 | 优先级 | 理由 |
|---|---|---|
| Human Vision（LMS 锥 / 杆视 / 光度视） | P1 | 色彩空间、ΔE、HDR Barten 的基础，不讲会显得凭空 |
| Display Technology（LCD / OLED / local dimming） | P2 | HDR 曲线讲完，但不讲「屏能不能显示」是半截 |
| Radiometry / Etendue 基础 | P2 | 变焦 / 光圈 / QE 都在悄悄用，不讲隐含假设多 |
| Computational Photography 深入 | P2 | 第 33 步已覆盖，P2 可拆成两步 |
| Semiconductor Front-end 工艺 | P3 | 不是 PhotonFall 核心，一段 150 字足够 |

## 建议的章节结构升级

**现状**（6 章）：
```
0. 先看全景
1. 镜头
2. 进传感器前
3. 像素
4. 结构
5. 读出与处理
6. 周边
```

**V2 建议**（7 章）：
```
0. 先看全景
1. 镜头                    # 不变
2. 进传感器前              # 不变
3. 像素                    # 不变
4. 结构                    # 不变
5. 读出与处理              # 不变
6. 显示与观察（新）         # 新章：人眼 + 显示端
7. 周边                    # 原第 6 章
```

第 6 章「显示与观察」内容：
- 新步 ∘ 人眼接光：LMS 锥 / 杆视 / 光度视 / 暗视 / 色恒常 / 元像
- 把现有「色彩空间 + 色深 + 色彩管理」（原第 29 步）移到这里（已依赖人眼理论）
- 新步 ∘ 显示技术：LCD / OLED / QD-OLED / Mini LED 的颜色 / 亮度 / ABL / local dimming

这样第 7 章（原第 6 章「周边」）只包含：机械快门、HDR 合成、图像格式、视频编码、存储、计算摄影。6 步，密度合适。

**不建议的变动**：不要把现有章再拆。镜头 10 步已经紧凑，再拆会更碎。

（全景 → 光电效应 → QE → LOFIC → 结构 → LOFIC 电容 → 堆栈 → 整颗芯片 → 噪声 → CDS → ADC）

## 和 V1 比较

- V1 没有正式的知识架构分析，这是本次新增。
- V1 列出缺口但没对齐到现有步的具体位置。本文明确列到步 idx。
- V1 的建议多是「加 N 个新实验」，本文优先建议**先在现有步中扩充**，再新增。

## 不建议做的

1. **再拆镜头章**。十步已经密，再拆会碎。
2. **把 LOFIC 从第 3 章 / 第 4 章分开**。它横跨两章确实有重复感，但现有 related 跳转足够。
3. **引入外部框架（如 Vue/React）**。单页 vanilla JS 的交付速度无可替代。
4. **为了覆盖面增加未来 / 未上市技术**。保持当前「最后核对日期 = 2026-11-16」的审慎口径。
