# PhotonFall 界面简化：3D 全屏 + 浮动小卡 + 详细抽屉

日期：2026-11-13　状态：待用户确认（方向 C、实现方式已在对话中确认）
分支：`simplify`，从 `lens-coating`（PR #3，33 步版本）切出。

## 为什么做

用户要"整体交互、UI 更简洁，让用户更容易理解和操作"。当前问题（用户确认了这份判断）：

- 导航占顶部约三分之一：7 个章节按钮加时间轴（两行）、进度条、本章步骤标题（1–3 行）。
- 每一步的讲解栏太长：入门句、控件和小图、进阶、硬核、演进卡（每张 4 格，最多 3–4 张）、元器件、上一步/下一步，约 1.5 屏。
- 3D 里同时显示约 10 个标注，挤在一起、被裁掉。
- 操作提示是一行小字，新手不会读。
- 演进卡视觉太重，抢正文注意力。

## 目标

1. 3D 占满整页，讲解压缩成左下角一张浮动小卡；更多内容放进"详细"抽屉。
2. 导航压成顶部一行小药丸：☰ 目录、当前位置（"3 像素 · 第 2/3 步"）、🕰 时间轴、?。
3. 3D 默认只显示入门句里提到的标注，其余收起，可以一键显示全部。
4. 第一次进来时弹出三张操作提示小卡，之后点"?"再看。
5. 手机上小卡变成底部抽屉，上滑展开成"详细"。

## 非目标

- 不改内容：所有文字、演进节点、小图一个字不删，只换位置。
- 不改章节划分、步骤编号、路由格式、时间轴视图的结构（只统一顶部样式）。
- 不改 3D 场景的运动和动画逻辑。
- 不引框架、不加构建、不升级 three.js。

## 反目标

- 新手看不到看懂这一步所需的东西（控件或关键小图被藏进抽屉）。
- 手机上小卡把 3D 挡得看不见主体。
- 改完反而更难找：目录、时间轴、上一步/下一步不明显。
- 现有交互退化（变焦对焦光圈快门 ISO 拍照、各步按钮滑块、点标注看元器件、关键词高亮、全景导览、时间轴双向跳转、深链接、键盘方向键）。

## 约束

- 普通 `<script>`、按顺序加载共享全局；不能用 ES modules / fetch；双击 `index.html` 能用。
- 颜色用 `:root` 变量（CSS）和 `PAL`（canvas）；继续浅色纸感卡片 + 深色 3D 舞台的风格。
- 现有面板元素的 id 不变（`#ctl #vfwrap #txwrap #chipctl #dnwrap #isp` 和全部 `[data-pn]` 面板、`#lead #adv #hard #evo #compwrap #title` 等），JS 继续按 id 找它们；只改它们在 DOM 里的位置和样式。
- `localStorage` 只用来记"已看过提示"，读写都包 try/catch，失败时当作没看过。

## 考虑过的做法

页面结构比较过三种：A 标签页（左栏保留，内容分标签）、B 一个"展开更多"、C 3D 全屏 + 浮动小卡 + 详细抽屉。用户选 **C**。

实现方式：
| 做法 | 结论 |
|---|---|
| **在现有页面上改布局**：`#view` 铺满，原左栏拆成浮动小卡 + 右侧抽屉，元素 id 和逻辑保留，新增标注按需、目录弹层、提示卡 | **选这个** |
| 推倒重写界面层（换框架） | 违反无构建约束，贵，用户看不到更好的效果 |
| 保留左栏只做删减 | 就是 A/B 方向，和 C 冲突 |

## 已定的设计

### 画面结构（电脑，宽于约 768px）

- `#view`（3D）铺满整个视口。
- **顶栏**（浮在 3D 上，左上到右上一行小药丸，浅色半透明）：
  - `☰ 目录`：点开一个目录弹层，按章节列出全部步骤标题，当前步高亮，点击跳转；Esc 或点外面关闭。
  - 当前位置：`<章号> <章名> · 第 x/y 步`（x/y 是本章内序号；第 0 章显示"先看全景"）。
  - `🕰 时间轴`：进入 `#/timeline`。
  - `标注`开关：在"只显示提到的"和"显示全部"之间切换（见下）。
  - `?`：重新打开操作提示。
  - *（实现者的决定）* 原来的全局进度条 `#prog` 保留，改成贴在视口最上沿的一条细线（2–3px，砖红），宽度仍按"当前步 / 最后一步"计算，`panel.js` 里更新它的逻辑不变。
- **浮动小卡**（左下角，宽约 340px，最高不超过视口高度减去顶栏，内容多时卡片内部滚动），从上到下：
  1. 标题（`#title`）
  2. 入门句（`#lead`，关键词可点）
  3. 本步控件（滑块、按钮）
  4. 本步关键小图（规则见下），点击放大（弹层显示大图，Esc 关闭）
  5. 来龙去脉小标签：每个关联演进节点一枚小药丸"🕰 年份 · 标题"，点击进时间轴并打开该节点
  6. 按钮行：`详细 ↗`、`←`（上一步）、`下一步：<标题> →`（主按钮）
  - 卡片右上角一个"收起"按钮：收起后只剩一条"<标题> · 展开"，再点展开。收起状态在切换步骤时保持。
- **详细抽屉**（右侧，宽约 min(460px, 42vw)，打开时 3D 仍可见、可操作）：
  - 顶部标题 + 关闭按钮（Esc 也关闭）。
  - 三个标签：**深入**（进阶 `#adv`，后接硬核 `#hard`，硬核用一个小标题"硬核"分开，不再折叠）、**来龙去脉**（完整演进卡 `#evo`）、**元器件**（`#compwrap` 的列表）。某个标签没内容时隐藏。
  - 该步除"关键小图"以外的其他小图和面板放在"深入"标签的最上面。
  - 打开时焦点移到抽屉标题；关闭时焦点回到"详细"按钮。
  - 抽屉开关状态在切换步骤时保持（打开着翻下一步，抽屉内容跟着更新）。

### 控件和小图放哪（规则）

- **进卡片**：所有滑块和按钮类控件：`#ctl`（相机控件）、`#chipctl`、`#tourpn`、`#coatpn`、`#shutpn`、`#storpn`、`#mlsctl`、`#quadctl`、`#abwrap`（复选框）、`#pdafwrap` 和 `#snrwrap` 里的滑块、`#ibwrap` 的按钮。
- **关键小图进卡片**（每步最多一张）：
  | 步骤（场景） | 关键小图 |
  |---|---|
  | 有 `#vfwrap` 的 macro 步 | 取景器 `#vf`（拍照结果 `#photo` 放抽屉） |
  | 4 相位对焦 | `#pdc` |
  | 5 光圈与虚化 | 取景器（艾里斑 `#airy` 放抽屉） |
  | 8 镀膜 | 反射率图（`#reflwrap` 的画布） |
  | 10 防抖 | `#ibc` |
  | 12 微透镜与拜耳 | `#spec` |
  | 16、17 tx 场景 | 电势图 `#pot`（时序图 `#tm` 放抽屉） |
  | 22 噪声 | `#snr`（样片 `#npatch` 放抽屉） |
  | 24 ADC | `#adcc` |
  | 25 卷帘/全局 | `#shc` |
  | 23 逐行读出 | `#dnwrap`（RAW 数值） |
  | 26 ISP | 九格图里的最后一张（⑨），其余在抽屉 |
  | 11 前玻璃 | 摩尔纹对比放抽屉，卡片不放图 |
  - 表里没列的步骤：卡片不放图。
- 实现上，面板元素按"进卡片 / 进抽屉"移动到卡片的控件区或抽屉的"深入"顶部；一个面板里同时有控件和图（如 `#snrwrap`、`#pdafwrap`、`#ibwrap`）时，把控件部分和图部分拆成两个容器，各自归位。拆分后保持原有 id 和事件绑定。

### 标注按需显示

- 默认：只显示当前步入门句里 `data-hl` 引用的标注（逐字匹配标注文字），其余标注隐藏。
- 顶栏"标注"开关切到"全部"后，显示该场景全部标注；开关状态在切换步骤时保持。
- 点击关键词（`hl`）时，即使该标注当前被隐藏也临时显示并高亮。
- 点击标注弹出元器件说明的交互保留（对可见的标注）。
- 第 0 步全景导览中，导览当前段落调用 `hl` 的标注照常显示。
- *（实现者的决定）* 做法：在 `app.js` 的 `frame()` 里，标注显示条件从"所在组可见且在镜头前"改成"所在组可见、在镜头前，并且（标注开关为全部，或该标注被本步入门句提到，或该标注正被 `hl` 临时点亮）"。`hl()`（关键词点击和导览都走它）给目标标注打一个临时点亮标记，持续到高亮结束。标注是叠在 3D 上的界面层，改这个显示条件不算改 3D 运动逻辑。

### 操作提示（第一次进入）

- 第一次打开页面（`localStorage` 没有标记）时，在 3D 上依次显示三张小卡，每张一句话加"下一张 / 知道了"：
  1. 拖动画面可以转动，双指或滚轮缩放。
  2. 文字里带下划线的词可以点，3D 里会标出来。
  3. 点"下一步"往下走；"详细"里有更深的内容和来龙去脉。
- 看完或点"知道了"后写入标记。之后点顶栏 `?` 重新显示。
- 提示显示时不打断全景导览。
- 原来底部那行操作提示文字（`#hint`）删除。

### 手机（窄于约 768px）

- 3D 铺满；顶栏缩成：`☰`、当前位置（短写"3 像素 · 2/3"）、`🕰`、`?`（"标注"开关放进目录弹层底部）。
- 浮动小卡变成**底部抽屉**，三个高度：
  - 收起：只露一条标题。
  - 默认：标题、入门句、控件、关键小图、按钮行（最高约 45% 屏高，内部滚动）。
  - 展开：上滑或点"详细"后几乎全屏，显示"深入 / 来龙去脉 / 元器件"三个标签。
- 通过拖动把手或点击把手在三档之间切换；不依赖复杂手势库，用 pointer 事件实现。
- 页面没有横向滚动。

### 时间轴视图

- 结构不变；顶部换成同样的药丸式顶栏（☰ 目录、"技术演进时间轴"、回到讲解）。打开时隐藏浮动小卡和详细抽屉。

### 键盘与焦点

- 方向键左右切步保留（在输入框、目录弹层、时间轴里不生效，与现在一致）。
- Esc 依次关闭：放大小图 → 目录弹层 → 详细抽屉 → 时间轴抽屉。
- 所有新按钮可 Tab 到、有可见焦点；目录弹层和抽屉用 `role="dialog"` 并有标题。

### 测试

- `node tests/check.js` 保持全过（数据层不变）。
- tests/smoke.js 现有断言里引用旧布局的部分（如 `#panel` 里的焦点、`#chnav`/`#sub`、`#hardwrap` 可见性）按新结构改写，保持原意。
- 新增断言：
  - 默认可见标注集合 = 入门句关键词对应的标注；切到"全部"后可见数增加。
  - 每步的控件元素在卡片里（不在抽屉里）；关键小图规则表里的步骤，对应画布在卡片里。
  - "详细"打开抽屉、三个标签切换、Esc 关闭、焦点回到"详细"按钮。
  - 卡片收起/展开；收起状态切步后保持。
  - 目录弹层能跳到任意步。
  - 清掉提示标记后刷新会出现提示卡，点"知道了"后刷新不再出现。
  - 电脑和手机宽度下页面都没有横向滚动；手机下默认高度的底部抽屉不超过屏高约 50%。
