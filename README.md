# PhotonFall · 光子落点

跟着一颗光子走完相机成像的全过程：从景物出发，穿过镜头、滤光片、微透镜和滤色片，落进像素的势阱变成电子，再经过读出电路、ADC 和 ISP，最后变成一张照片。

用 Three.js 做成 33 步可交互的 3D 讲解（第 0 步先看全景，第 1–32 步是正文），每一步都有动画、关键词点击高亮 3D 标注，进阶和硬核内容放在"详细"抽屉的深入标签里；场景里的元器件可以点开看说明。另有时间轴视图，把 25 个技术演进节点排成六个年代 × 五条线索。

## 内容

| 章 | 步骤 | 覆盖内容 |
|---|---|---|
| 0 先看全景 | 0 | 自动镜头导览（约 30 秒），可重播 |
| 1 镜头 | 1–10 | 光从景物出发、镜头与变焦、对焦、相位对焦、光圈与虚化、像差与校正、镜头里的每片镜片（各镜组和特殊镜片的分工）、镜片镀膜（种类、怎么镀、反射率曲线、眩光与鬼影）、快门 ISO 与拍照、防抖 |
| 2 进传感器前 | 11–14 | 传感器前的几片玻璃（含摩尔纹对比）、微透镜与拜耳滤色片（含透光曲线）、微透镜偏移、四合一像素 |
| 3 像素 | 15–17 | 光子变成电子、单个像素 4T 结构（电势图 + 时序图）、LOFIC 与双转换增益 |
| 4 结构 | 18–21 | 三种像素结构（前照式 / 背照式 / 堆栈式）、LOFIC 电容五种位置、两层与三层堆栈式 LOFIC、整颗传感器布局 |
| 5 读出与处理 | 22–26 | 噪声与信噪比、逐行读出、单斜率 ADC、卷帘与全局快门、ISP 九步 |
| 6 周边 | 27–32 | 机械快门与同步速度、HDR 与多帧合成、颜色空间 / 色深 / 色彩管理、视频编码（YUV → H.265）、存储卡 / 总线 / 传输、计算摄影（夜景 / 人像 / 超分） |
| 时间轴 | `#/timeline` | 25 个演进节点，六个年代 × 五条线索（镜头、传感器、图像处理、存储与传输、产品形态）；每个节点展示解决了什么问题、带来了什么新问题、推动力与行业变化，可从讲解页直接跳入，也可从时间轴一键回到原理页 |

每一步的浮动小卡包含：入门句（关键词可点击高亮 3D 标注）、本步控件与关键小图、来龙去脉小标签（点击进时间轴）、详细与上一步/下一步按钮。点"详细"打开右侧抽屉，分三个标签：深入（镜头读数和其余小图，以及进阶和硬核内容，含公式 / 表格 / 厂商细节）、来龙去脉（完整演进卡）、元器件（本步出现的元器件列表）。

可以交互的部分包括：变焦、对焦、光圈、快门、ISO 和拍照，取景器画面、景深、弥散圆、艾里斑都按公式实时计算；另外有镀膜开关和反射率曲线的入射角滑块、防抖开关、相位对焦离焦滑块、微透镜偏移开关、四合一模式切换、像素尺寸与噪声参数，以及「把电路叠到像素下面」的堆栈式切换。

## 运行

不需要构建，直接用浏览器打开 `index.html` 就行。three.js r128 从 CDN 加载，所以需要联网。

也可以起一个本地静态服务器：

```bash
python3 -m http.server 8000
```

然后打开 <http://localhost:8000>。

操作方式：拖动旋转；双指滑动或 Shift + 拖动平移；双指捏合或鼠标滚轮缩放。3D 铺满整页，左下角浮动小卡显示当前步的入门句、控件和关键小图；顶栏小药丸依次是 ☰ 目录、当前位置（点它也打开目录）、🕰 时间轴、标注开关、? 操作提示。点"详细 ↗"打开右侧抽屉，包含深入（进阶 + 硬核）、来龙去脉和元器件三个标签；Esc 依次关闭最上层（放大图 → 目录 → 操作提示 → 元器件说明 → 详细抽屉 → 时间轴抽屉）。左右方向键切换步骤；点标注看元器件说明。手机上小卡变成底部抽屉，拖动把手或点"详细"可在三档高度之间切换。深度链接：`#/step/<n>` 直达某步，`#/timeline` 或 `#/timeline/<id>` 直达时间轴或特定节点。

### 测试

```bash
# 静态检查（Node.js，零依赖）：路由、步骤结构、演进数据，共 9 项
node tests/check.js

# 浏览器冒烟测试：先起服务器，再在浏览器控制台执行
# python3 -m http.server 8765
# 在控制台：
#   const r = await fetch('/tests/smoke.js'); eval(await r.text());
#   await smoke()   // 期望 {ok: true, fails: []}
```

完整的冒烟测试大约要 25 秒。如果控制台或自动化工具有时间限制，先不加 await 启动（如 `window.__r = smoke()`），过一会儿再读结果（`await window.__r`）。页面在隐藏或后台标签页里时 requestAnimationFrame 可能不触发，动画相关的检查会失败。

## 准确性说明

- 镜头规格取自 Sony 官网。镜筒里的镜片分组只是示意，不是真实的光学设计；光线统一在等效主平面偏折。第 7 步讲的各镜组分工是变焦镜头的典型做法，Sony 没有公开这支镜头每一片的设计。
- 第 8 步的反射率曲线：裸玻璃、单层和六层膜按薄膜干涉公式计算（忽略色散和吸收），六层膜是自拟的示例膜系；亚波长结构用渐变折射率层近似，是示意。
- 物方距离是压缩画的，像方（镜头到传感器）按真实比例。
- 滤色片曲线、像差程度、噪声参数、电容大小和各层厚度都是示意值。
- 各厂商具体传感器的结构（比如 LOFIC 电容放在哪一层）通常不公开，页面讲的是业界常见做法。
- 演进线的年份和事件经网络核对，"约"表示不确定；每个节点在详情里列了来源。
- 演进线侧重讲清楚「为什么出现」和「带来了什么新问题」，不追求完整的技术史，部分次要节点有所省略。
