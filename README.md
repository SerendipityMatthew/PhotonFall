# PhotonFall · 光子落点

跟着一颗光子走完相机成像的全过程：从景物出发，穿过镜头、滤光片、微透镜和滤色片，落进像素的势阱变成电子，再经过读出电路、ADC 和 ISP，最后变成一张照片。

用 Three.js 做成 24 步可交互的 3D 讲解，每一步都有动画和文字说明，场景里的元器件可以点开看说明。

## 内容

| 部分 | 步骤 |
|---|---|
| 镜头（以 Sony FE 50-150mm F2 GM 为例） | 光从景物出发、变焦、对焦、相位对焦、光圈虚化与衍射、像差与校正、快门 ISO 与拍照、防抖 |
| 传感器前段 | 红外截止 / 低通滤镜 / 保护玻璃（含摩尔纹对比）、微透镜与拜耳滤色片（含透光曲线）、微透镜偏移、四合一像素 |
| 像素 | 光子变成电子、单个像素 4T 结构（电势图 + 时序图）、LOFIC 与双转换增益 |
| 结构 | 前照式 / 背照式 / 堆栈式 / LOFIC 像素、LOFIC 电容五种位置、两层与三层堆栈式 LOFIC、整颗传感器布局 |
| 读出与处理 | 噪声与信噪比、逐行读出、单斜率 ADC、卷帘与全局快门、ISP 九步 |

可以交互的部分包括：变焦、对焦、光圈、快门、ISO 和拍照，取景器画面、景深、弥散圆、艾里斑都按公式实时计算；另外有防抖开关、离焦滑块、微透镜偏移开关、四合一模式切换、像素尺寸与噪声参数，以及「把电路叠到下面」的堆栈式切换。

## 运行

不需要构建，直接用浏览器打开 `index.html` 就行。three.js r128 从 CDN 加载，所以需要联网。

也可以起一个本地静态服务器：

```bash
python3 -m http.server 8000
```

然后打开 <http://localhost:8000>。

操作方式：拖动旋转；双指滑动或 Shift + 拖动平移；双指捏合或鼠标滚轮缩放；左右方向键切换步骤；点标注看元器件说明。

## 文件结构

```
index.html        页面骨架：左侧讲解栏 + 右侧 3D 场景
css/style.css     样式
js/core.js        基础：工具函数、景物图、three.js 场景与相机
js/steps.js       每一步的标题、镜头位置、讲解文字
js/lens.js        镜头、景物、传感器与取景器
js/pixel-array.js 4×4 像素阵列与逐行读出
js/pixel-4t.js    单个像素 4T 结构
js/lofic.js       LOFIC 工作过程
js/structures.js  各种像素结构对比
js/chip.js        整颗传感器布局
js/optics-extras.js  衍射、像差、传感器前玻璃、相位对焦、防抖
js/sensor-extras.js  透光曲线、微透镜偏移、四合一
js/readout.js     噪声、ADC、卷帘与全局快门
js/isp.js         ISP 九步
js/components.js  元器件说明
js/app.js         步骤切换、动画循环、启动
```

脚本都是普通的 `<script>`，按 `index.html` 里的顺序加载，彼此共享顶层变量，所以加载顺序不能乱。新增一步的做法：在 `steps.js` 里加一条，场景代码放进对应章节的文件；如果需要新的 3D 组，记得在 `app.js` 的 `GR` 和动画循环里登记。

## 准确性说明

- 镜头规格取自 Sony 官网。镜筒里的镜片分组只是示意，不是真实的光学设计；光线统一在等效主平面偏折。
- 物方距离是压缩画的，像方（镜头到传感器）按真实比例。
- 滤色片曲线、像差程度、噪声参数、电容大小和各层厚度都是示意值。
- 各厂商具体传感器的结构（比如 LOFIC 电容放在哪一层）通常不公开，页面讲的是业界常见做法。
